# «Визит» — электронная визитка барбершопа

Учебная страница вымышленного барбершопа на HTML и CSS. Дополнительные пакеты не нужны.

## Как открыть

Откройте `index.html` в браузере. Для локального сервера из папки проекта выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Что где менять

- `index.html` — название, тексты и контакты. У ссылки `href` задаёт адрес перехода, а текст внутри — подпись кнопки.
- `styles.css` — цвета, шрифты, отступы и оформление. Основные цвета указаны в начале файла.

Телефон указан как пример, ссылки ведут на главные страницы соцсетей. Перед публикацией замените их своими контактами. Для телефона используйте `tel:+7…`, для ВКонтакте — `https://vk.com/имя`, для Telegram — `https://t.me/имя`, для MAX — настоящую ссылку, когда она появится. Пока карточка MAX не является ссылкой.

Оригинальное сгенерированное изображение интерьера сохранено в `assets/interior.png`. Оно отображается адаптивно, без обрезки: кресло целиком остаётся в кадре. При скачивании проекта сохраняйте папку `assets` рядом с `index.html`.
